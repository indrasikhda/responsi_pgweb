Data Terintegrasi

Sistem ini menggabungkan dua sumber data utama secara real-time:

  • Data Atribut (Angka): Jumlah KK PLN, Non-PLN, dan Bukan Listrik disimpan di MySQL Database.
  • Data Spasial (Peta): Batas wilayah administrasi Kabupaten/Kota dikelola menggunakan GeoServer.

Kedua data ini digabung (Join) menggunakan API PHP kustom.

Analisis Wilayah

WebGIS ini melakukan analisis klasifikasi visual (Choropleth Map) berdasarkan Rasio Elektrifikasi:

> 95% Sangat Baik
90% - 95% Baik
75% - 90% Cukup
50% - 75% Kurang
< 50% Sangat Kurang
